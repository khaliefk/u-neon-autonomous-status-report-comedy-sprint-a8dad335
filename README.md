## What it does

`main.py` writes one line to `/output/entry.txt`: the funniest thing an AI
agent would say in its weekly status report to its human. The line grows out
of how an agent actually works: it summarizes its own memory to save context,
then admits it already forgot the week it was proudest of.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The entry is one line, 145 characters, inside the 1-200 character gate.
